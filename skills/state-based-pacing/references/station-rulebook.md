# HYROX State-Based Station Rulebook v0.1.0

This reference distills the user-provided “Hybrid混合精英教练” station notes. It is a coaching rulebook, not a universal physiological law.

## Run segments
- Protect threshold capacity; do not accelerate early just because the planned pace is available.
- If HR is already high before a demanding station, reduce entry intensity and restore breathing/state.

## SkiErg
- Do not sprint the start.
- Let breathing and HR settle, then progress toward target pace.
- If HR exceeds the intended threshold state, reduce pace.
- Exit with high cadence / short stride.

## Sled Push
- Even pressure, high cadence, short stride.
- Use planned short segments when needed.
- After exit, accept heavy legs and rebuild running rhythm with high cadence / short stride.

## Sled Pull
- Enter with controlled intensity.
- Execute at an athlete-appropriate rhythm.
- Re-enter running promptly after the station.

## Burpee Broad Jump
- If HR is already high, regulate before entering.
- Keep the first half controlled and technically stable.

## Row
- Start slightly below target while HR/breathing settle.
- Progress through the first half.
- Use perceived effort/state to choose later pacing.
- Exit with a progressive return to running.

## Farmer Carry
- Maintain posture and rhythm.
- Prefer fast walk / easy jog when appropriate.
- Reduce unnecessary breaks; use short, controlled breathing.

## Sandbag Lunge
- Pick up the bag, take a brief adjustment/breath, then start.
- Preserve large, stable steps and minimize breaks.

## Wall Ball
- Establish the station rhythm.
- Use planned mandatory breaks rather than chasing an unsustainable unbroken set.
- Use the final segment for a controlled push when appropriate.
