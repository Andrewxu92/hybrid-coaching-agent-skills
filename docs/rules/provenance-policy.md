# Provenance Policy v0.1.0

Every substantive coaching rule in the intelligence layer should be traceable to:

1. **User methodology** — supplied by the domain expert and preserved as coaching doctrine unless explicitly revised.
2. **External research** — used to validate boundaries, uncertainty, or general mechanisms; never silently substituted for the user's method.
3. **Agent inference** — architecture/routing inference used to connect skills; label it as inference when it could be mistaken for domain doctrine.

Unsupported claims should remain hypotheses or be omitted.
