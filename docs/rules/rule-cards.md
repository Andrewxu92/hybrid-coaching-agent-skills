# Rule Cards v0.4

Legend: SOURCE = explicitly present in supplied material; INFERENCE = operational rule inferred from source structure; RESEARCH = supported or qualified by external literature.

## Capability

### R-CAP-001
Strength, Speed, Endurance are first-level athlete capability dimensions.

Status: SOURCE / CONFIRMED

### R-CAP-002
Core capability scores are continuous 0–100; 60 / 80 / 100 are benchmark anchors rather than hard population categories.

Status: CONFIRMED DECISION

### R-CAP-003
Basic / Specific / Hybrid are developmental or expression layers, not mandatory core score fields.

Status: CONFIRMED DECISION

### R-CAP-004
Hybrid is not a fourth pillar; it describes interacting capabilities/tasks under a carried-over state.

Status: CONFIRMED DECISION + INFERENCE

## Gap and diagnosis

### R-DIAG-001
`Gap = Demand - Athlete` is the default v0.4 gap calculation.

Status: CONFIRMED DECISION

### R-DIAG-002
Run a limitation screen only when a meaningful gap remains unexplained or the response pattern is diagnostically useful.

Status: INFERENCE

### R-DIAG-003
`HR high + pace limited` is a central-limitation hypothesis, not a medical diagnosis.

Status: SOURCE → operational inference

### R-DIAG-004
`Breathing not highly stressed + legs cannot express pace` is a peripheral-limitation hypothesis.

Status: SOURCE → operational inference

### R-DIAG-005
When data conflict or are insufficient, output `unclear` rather than forcing a cause.

Status: INFERENCE

## Training decision

### R-ADAPT-001
Select the desired adaptation before routing to a mature method-selection skill.

Status: COMPOSITION

### R-ADAPT-002
Do not let a method selector become the primary diagnostic engine.

Status: ARCHITECTURAL RULE

### R-ADAPT-003
Use the least complex intervention that directly addresses the dominant gap and preserves required capacities.

Status: INFERENCE / simplicity principle

## Hybrid transfer

### R-HY-001
Operational Hybrid is present when multiple meaningful demands are linked with limited/continuous recovery and the earlier task changes the subsequent performance state.

Status: INFERENCE / v0.4 working definition

### R-HY-002
General → Specific → Hybrid → Performance is the default transfer ladder.

Status: SOURCE + INFERENCE

### R-HY-003
A session is not Hybrid merely because it contains two exercise types; meaningful state carry-over is required for the Hybrid label.

Status: INFERENCE

## Race pacing

### R-PACE-001
Protect threshold capacity when meaningful later demands remain.

Status: SOURCE

### R-PACE-002
High HR before a demanding station triggers an entry-intensity reduction / state reset.

Status: SOURCE

### R-PACE-003
Ski uses a conservative-to-progressive start.

Status: SOURCE

### R-PACE-004
Row uses progressive pacing with later perceived-effort adjustment.

Status: SOURCE

### R-PACE-005
Pacing is state-dependent: current HR, pace, breathing, fatigue, target and next demand can change the recommended action.

Status: INFERENCE from multiple source rules

## Station execution

### R-ST-001
Sled Push: steady, high cadence, short stride, planned segmentation when needed.

Status: SOURCE

### R-ST-002
Sled Pull: controlled rhythm/technique and prompt return to running.

Status: SOURCE

### R-ST-003
BBJ: stable rhythm/technique; avoid an aggressive early pace.

Status: SOURCE

### R-ST-004
Farmers Carry: posture/rhythm; minimize unnecessary stops.

Status: SOURCE

### R-ST-005
Sandbag Lunge: brief setup/breath, controlled large steps, minimize avoidable rest.

Status: SOURCE

### R-ST-006
Wall Balls: planned reps/rest, avoid unsustainable early sets, push late.

Status: SOURCE

## Planning / concurrent training

### R-PLAN-001
Concurrent strength and endurance work should be organized around the athlete's target and fatigue constraints rather than treated as automatically incompatible. Current evidence suggests interference is context-dependent rather than universally present. 

Status: RESEARCH

### R-PLAN-002
Sequence and spacing are planning variables, not absolute physiological laws; optimize them when a quality-sensitive quality (e.g. maximal strength/speed) is a priority.

Status: RESEARCH + EXISTING SKILL COMPOSITION

## Provenance convention v0.1.0

- `SOURCE`: directly stated in the supplied Hybrid coaching material or diagrams.
- `CONFIRMED DECISION`: explicitly agreed in this project conversation.
- `INFERENCE`: operational abstraction made while converting source material into an agent rule.
- `COMPOSITION`: routing rule created by combining existing skills.
- `RESEARCH`: external evidence used to qualify, not replace, the source methodology.

Image-only material is marked as source-derived from the supplied diagrams; exact line-level traceability is unavailable unless the diagram text is separately provided in machine-readable form.
