# HYROX Plan Audit

## Audit layers
1. Existing repository safety/structure rules.
2. Phase fit and training-order rules.
3. HYROX station coverage and density.
4. Athlete-gap alignment: does the plan address the declared priority gap?
5. Hybrid-transfer logic: does competition-specific work create meaningful state carry-over rather than merely combine exercises?

## Output
- P0 critical violations
- P1 important issues
- P2 optimization notes
- Minimal corrections

## Boundary
Do not replace the upstream athlete assessment or target-selection process.
